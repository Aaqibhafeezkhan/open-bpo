# Changelog

All notable changes to open-bpo are documented here. The project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and uses semantic versioning.

## [Unreleased]

### Added

- Root build and lint entry points and complete CI validation.
- Provider integration guide for telephony, media orchestration, STT, TTS, and LLM adapters.
- Payment-reminder recipe and QA checklist examples.
- Contributor roadmap and refreshed GitHub contribution templates.

### Changed

- Reworked the README around the runnable local path and QualiaBits branding.

## [0.1.0] - 2026-10-25

### Added

- Fastify API, BullMQ worker, React console, Redis, and Postgres scaffold.
- Mock voice-session loop and Twilio/LiveKit provider stubs.
- Deterministic recipe checklist scorer and unit test.
- Lead-qualification and support recipes.
- Docker Compose quickstart and golden-path script.
